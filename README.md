A tiny deterministic program that writes one word — practice, the word my ex would use to describe me — to /output/entry.txt: one word, nothing else. It scores a short list of candidate words against the judge's five criteria (funniest and most painfully honest first) and writes the highest-scoring one.

## Run it

```sh
python3 main.py
```
